01

End-to-End RAG System on the Wix Knowledge Base

An end-to-end retrieval-augmented generation system for Wix customer support.

Background
Built on 6,221 official Wix help articles and 400 real support tickets. The scenario splits into two hard question types — single-document exact match and multi-document multi-hop reasoning — so I designed an evaluation suite and drove every optimisation with offline experiments.
Evaluation design
Analysing real tickets surfaced those two scenarios, so I re-cut the metrics per question type — Hit@5 and MRR for single-document questions, Full@5 for multi-document ones — and made joint improvement across every question set the bar for adopting a change.
Model selection
Benchmarked MiniLM, bge-small, E5-large and others. With comparable quality, MiniLM brought retrieval latency down to 1/4 and index build time to roughly 1/20 of the original plan — a large gain in responsiveness.
Retrieval optimisation
For weak single-document accuracy I ran controlled experiments on chunking, retrieval strategy and reranking, and traced the biggest gain to contextual embedding. The final recipe — stop-word removal, document metadata on every chunk, and an 8:2 blend of semantic and keyword retrieval — lifted Top-5 recall on single-document QA pairs from 62% to 77%. For low full recall on multi-document questions, a small model rewrites the query and an agentic loop lets it retrieve autonomously, taking Full@5 from 35% to 75%.

02

Landy — Job-Hunting Assistant Agent

An AI job-hunting assistant agent for campus recruiting.

Background
Company due diligence, résumé rewriting and interview prep are the most repetitive — and slowest — parts of campus recruiting. Landy is a job-hunting assistant agent built to take that weight off the candidate.
Agent architecture
A workflow split into four sub-agents — JD parsing, business research, résumé rewriting and mock interview. Research and rewriting run in parallel to cut end-to-end latency. The rewriting agent uses RAG over a ChromaDB vector index of the user's experience, pulling the passages that match JD keywords in real time; a HITL reflection loop then writes back into Memory, so user preferences persist and the agent grows more personalised over time.
Prompting & evaluation
Built an evaluation system scored on JD match and user satisfaction, assembled a high-quality dataset, and layered LLM-as-judge on top of human annotation to drive prompt optimisation. After iteration, the JD match rate of AI-rewritten résumés rose by about 35%.
